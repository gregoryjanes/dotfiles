# Literature Review Workflow

When performing a literature review for a paper section:

1. **Identify the topic area** (e.g., vortex identification, centerline extraction, vortex models)
2. **Check existing citations** in the .bib file and paper text
3. **Search for seminal/foundational works** that should always be cited
4. **Search for recent advances** (last 5 years) in the specific sub-area
5. **Cross-reference** — ensure any method described or compared against is properly cited
6. **Check for missing citations** — if we describe a technique, we must cite where it came from

## Key venues to search:
- Journal of Fluid Mechanics
- Physics of Fluids
- Journal of Computational Physics
- Experiments in Fluids
- AIAA Journal
- International Journal for Numerical Methods in Fluids
- IEEE Transactions on Visualization and Computer Graphics (for centerline extraction methods)

## Citation checklist for openvortex papers:
- [ ] All vortex identification methods mentioned are cited
- [ ] All centerline extraction methods mentioned are cited
- [ ] All numerical methods used are cited (L-BFGS-B, Dijkstra, Savitzky-Golay, etc.)
- [ ] All vortex models implemented are cited
- [ ] All software dependencies are cited
- [ ] Related open-source packages are mentioned and cited
